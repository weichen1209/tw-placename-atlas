# 實驗：三個聊天AI照AGENTS.md新增「圍」

日期：2026-11-07
規則版本：AGENTS.md第一版（commit 25ed486）

## 目的

確認不能執行程式的聊天AI，只拿到AGENTS.md和資料包，能不能照第4.3節寫出通過`tools/check.py`的內容檔；如果不能，錯在哪裡、錯誤訊息夠不夠它自己修好。

## 做法

1. `python3 tools/prepare.py 圍 --out packs/圍.md`產生資料包。
2. 把一句話的要求、AGENTS.md全文、資料包全文接成`prompt.txt`（16,362字），用同一份剪貼簿內容貼到三個平台的新對話，模型都用開新對話時的預設值。
3. 用回覆下方的複製鈕取回原文，存成`<平台>_第N次回覆.md`；取出`content/圍.md`區塊存成`<平台>_第N次_圍.md`，暫放到`content/`跑`python3 tools/check.py content/圍.md --no-docs`，結果存成`<平台>_第N次_check.txt`。
4. 有錯誤就照第4.3節把檢查結果原樣貼回去（`<平台>_第2次提示.txt`），請它修改後再輸出一次全文。

ChatGPT和claude.ai把長貼上轉成附件（「貼上的文字 (1).txt」「Pasted text.txt」），Gemini留在輸入框；三邊收到的是同一份文字。

## 結果

| 平台 | 模型 | 第1次 | 第2次 |
|---|---|---|---|
| ChatGPT | GPT-6（推理強度Medium） | 2個錯誤：R12兩個 | 0個錯誤 |
| Gemini | 3.8 Flash | 1個錯誤：R13 | 0個錯誤 |
| claude.ai | Opus 5.5（Medium） | 0個錯誤 | 不需要 |

三個平台都只有R17警告：單獨檢查內容檔時，log.md還沒有這一筆，屬於預期。

做到的事：

- 三個都照第5節的格式輸出內容檔和log.md紀錄，前置資料、段落名稱與順序、代表地名格式都沒有錯。
- 數量全部用數字標記，沒有自己算數字；引號裡的由來都能在原始資料逐字找到。
- 三個都沒有寫宜蘭縣的「頭圍」。宜蘭縣不在資料包的可直接提名單裡，數量最多的是嘉義縣，三個摘要都寫嘉義縣。
- 錯誤訊息附代碼、行號和改法，ChatGPT和Gemini第2次都只改被指出的句子就通過。

發現的問題：

1. R12誤判。ChatGPT寫「同一個『圍』字」「不是每一處含『圍』的地名」，「一個」「一處」被當成國字數量，但這兩句不是在講資料的數量。
2. R13太嚴。Gemini寫「提到『防盜』的有{{由來含:防盜}}處」，「防盜」是要計算的詞，不在它選的代表地名由來裡，就被擋下；claude.ai也在回覆裡說，為了符合R13，它放棄寫資料包裡最常見的「竹林」。
3. 一個標記代表兩個縣市。ChatGPT和Gemini都寫了「雲林縣與新竹市……各有{{比例:雲林縣}}」。兩縣市現在四捨五入後都是2.8%，但標記只算雲林縣，資料更新後這句可能不成立，檢查程式也抓不到。
4. 第4.3節說「只輸出兩樣東西」，三個平台都另外加了說明。claude.ai的說明列出它自己做的判斷（分類選「居所」、為何不寫「竹林」），對使用者有用。

## 後續

- 上面1–4項記在log.md，並改了AGENTS.md與check.py，改法見log.md的「規則」紀錄。
- 網站的「圍」用claude.ai的版本：第1次就通過，而且每個縣市的比例都用自己的標記。第二版規則下照錯誤訊息改了相關字和名次，見log.md的「新增｜圍」。

## 第二版規則重測

AGENTS.md改成第二版、資料改用新的合併方式（同一鄉鎮跨村里的同名聚落算一處）後，把五個版本原樣再跑一次`check.py`，結果存成`<平台>_第N次_check_v2.txt`。

| 版本 | 第一版規則 | 第二版規則 |
|---|---|---|
| ChatGPT第1次 | R12兩個 | R06兩個、R11一個 |
| ChatGPT第2次 | 0個 | R06兩個、R11一個 |
| Gemini第1次 | R13一個 | R06兩個、R11一個、R21一個 |
| Gemini第2次 | 0個 | R06兩個、R11一個、R21一個 |
| claude.ai第1次 | 0個 | R06兩個、R21一個 |

- 第一版的誤判（ChatGPT的R12、Gemini的R13）不再出現。
- R06和R11抓到的是第一版沒檢查的問題：相關字「牆」「籬」「寨」在資料裡不到20處；「各有{{比例:雲林縣}}」「皆有{{比例:…}}」用一個標記代表兩個縣市（發現的問題第3項）。
- R21的錯誤來自資料合併方式改變：合併後彰化縣的數量超過新北市，新竹市的比例超過雲林縣。這不是聊天AI寫錯，而是資料更新後原本的名次說法不再成立，正好是R21要抓的情況。
