# AGENTS.md：臺灣地名用字地圖

這份文件是本專案給AI（和協作者）的工作守則。新增或修改任何檔案前先讀完。每條規則都寫成了`tools/check.py`的檢查（代碼見第11節）；規則和檢查結果不一致時，先回報，不要自行改掉其中一邊。

## 1. 專案目的

- 一個字一頁，說明這個字在臺灣聚落地名裡的意思與分布，例如「窩」「厝」「埤」。
- 讀者是對地名、鄉土歷史有興趣的一般人和中小學老師；沒有背景知識也要看得懂。
- 分工：數字由程式從官方資料計算；字義只根據官方記載的由來；AI負責挑代表地名，把資料寫成好讀的說明。
- 網站：https://weichen1209.github.io/tw-placename-atlas/

## 2. 資料與計算方式

- 唯一的地名資料是`data/raw/settlements-2026.csv`（內政部「臺灣地區地名資料_聚落類」2026-09-24版）；縣市界線是`data/raw/county-boundary-1140318.zip`。來源、授權、SHA-256記在`data/SOURCE.md`。
- `data/raw/`的檔案不准修改（R18會比對SHA-256）。
- 程式的計算方式如下，寫說明時照這個意思理解數字：
  1. 同一縣市、鄉鎮、村里裡同名的紀錄算同一處：37,720筆合併成33,923處。
  2. 「地名含某字」指地名裡有這個字，不論在第幾個字。
  3. 「有由來」指至少有一筆官方由來，而且不是只寫「詳見某里」。
  4. 縣市的「比例」是該縣市的聚落中，地名含這個字的比例。
  5. 地圖只畫有經緯度的聚落。連江縣、金門縣、烏坵畫在左上角的小框。
  6. 由來文字會先解碼`&#24269;`這類編碼、把`<br>`換成換行；比對引文時忽略空白，『』視同「」。
- 已知限制：部分罕用字在原始資料裡變成「?」（例如糖廍的「廍」），這些字的數量會偏少；地名有「?」的聚落不能當代表地名。

## 4. 新增一個字

### 4.1 選字

- 從網站的「用字排行」（`docs/rank.html`）挑淡色、還沒收錄的字，或用`python3 tools/prepare.py <字>`看數量。
- 地名含這個字的聚落至少要20處（R03）。可以是兩個字的詞，例如「張犁」，最多兩個字。
- 一個字只有一個內容檔；已經有`content/<字>.md`就照第9節修改。

### 4.2 能執行程式時

1. `python3 tools/prepare.py <字> --out packs/<字>.md`產生資料包：數字標記和目前的值、各縣市數量與比例、可以直接提的縣市、前10鄉鎮、由來常見詞、候選代表地名與由來全文。`packs/`已列在`.gitignore`，資料包不放進repo。
2. 照第5節寫`content/<字>.md`。數量只用數字標記；引文只從資料包第5節複製。
3. 在`log.md`最後加一筆`## [YYYY-MM-DD] 新增｜<字>`，下一行用「- 」寫一句說明。
4. `python3 tools/check.py content/<字>.md`，照錯誤訊息改到0個錯誤。
5. `python3 tools/build.py`產生網頁。
6. `python3 tools/check.py`做全部檢查（含docs/是否最新），0個錯誤才算完成。
7. 本機預覽：`python3 -m http.server 8000 -d docs`，打開`http://localhost:8000/zi/<字>.html`，看地圖有紅點、縣市表有數字、引文有底線。

### 4.3 在聊天介面（不能執行程式）時

- 請使用者先做4.2第1步，把本檔和資料包交給你。
- 你只輸出兩樣東西：`content/<字>.md`的全文（放在一個程式碼區塊裡），和要加進`log.md`的那一筆紀錄。
- 不要自己算數字，不要用資料包以外的地名或由來。
- 使用者做完4.2第4–6步後，若把錯誤訊息貼回來，照錯誤代碼（第11節）修改，再輸出一次全文。

## 5. 內容檔格式

### 5.1 前置資料

檔案開頭兩條`---`之間，一行一個`欄位: 值`：

| 欄位 | 必填 | 規則 |
|---|---|---|
| 字 | 是 | 一到兩個漢字，和檔名相同 |
| 標題 | 是 | 這個字在地名裡的意思，最多12字，不加標點，例如「三面環山的凹地」 |
| 摘要 | 是 | 一句話，以「。」結尾，最多60字；首頁和搜尋結果會用到 |
| 分類 | 是 | 地形、水利、開墾、居所、軍事、族群、方位、產業、植物、動物，選一個 |
| 相關字 | 否 | 意思或用法相近的字，用「、」分隔，每個是單一漢字 |
| 建立 | 是 | YYYY-MM-DD |
| 更新 | 是 | YYYY-MM-DD，不早於建立 |

### 5.2 段落

只能有下面四個段落，照這個順序，標題寫成`## 段落名稱`：

| 段落 | 必填 | 字數 | 寫什麼 |
|---|---|---|---|
| 字義 | 是 | 80–300 | 這個字在地名裡的意思，以代表地名的官方由來為根據，關鍵句逐字引用 |
| 分布 | 是 | 60–300 | 地圖和縣市表看得到的事：總數、哪些縣市多、比例最高的縣市、最多的鄉鎮 |
| 代表地名 | 是 | 3–6個 | 清單，每行`- P編號 地名（縣市鄉鎮）`，至少來自兩個縣市 |
| 延伸觀察 | 否 | 最多300 | 由來裡看得到的其他規律，例如由來提到某個詞的有幾處 |

字數不算空白，一個數字標記算2字。字義、分布、延伸觀察寫成段落，不用清單、不分小標。

### 5.3 數字標記

內容檔裡不寫數字，寫標記；建置時才換成數字，資料更新後頁面跟著變。下表的例子是「窩」的值。

| 標記 | 換成 | 例子 |
|---|---|---|
| `{{總數}}` | 地名含這個字的聚落數 | 441 |
| `{{全部聚落}}` | 全臺聚落總數 | 33,923 |
| `{{占全部}}` | 總數占全臺聚落的百分比 | 1.3% |
| `{{有由來}}` | 其中有官方由來的聚落數 | 213 |
| `{{有座標}}` | 其中畫得上地圖的聚落數 | 355 |
| `{{縣市:苗栗縣}}` | 該縣市的數量；寫成`{{縣市:苗栗縣+新竹縣}}`是合計 | 175 |
| `{{比例:新竹縣}}` | 該縣市的聚落中，地名含這個字的百分比 | 8.2% |
| `{{占總數:苗栗縣+新竹縣}}` | 這些縣市占這個字總數的百分比 | 76.0% |
| `{{鄉鎮:新竹縣芎林鄉}}` | 該鄉鎮的數量，寫成縣市＋鄉鎮 | 42 |
| `{{由來含:客語}}` | 由來裡出現這個詞的聚落數，任何詞都可以 | 41 |

### 5.4 引號與代表地名

- 「」裡只能放：本字、相關字、資料裡的地名，或本頁代表地名官方由來的逐字片段（R13）。原文裡的「」改成『』。
- 引文一個字都不能改，包括標點；要省略中間的話，就拆成兩段引用。
- 要引用某一處的由來，先把那一處列進代表地名，讀者才看得到全文。
- 代表地名從資料包第5節挑：要含本字、有由來、至少兩個縣市（R10）；優先挑由來有解釋這個字的，其次挑數量多的縣市。

## 6. 寫作規則

- 繁體中文、臺灣用語；一律寫「臺」（臺灣、臺南市）。
- 句子短、就事論事：不寫感想，不用比喻、反問和emoji。
- 中文和英文、數字、數字標記之間不空格；標點用全形。
- 只寫資料看得到的事：
  - 數量一律用數字標記；不要寫「三百多處」「九成」這類國字數量（R12）。
  - 「大多、多數、大部分、集中、幾乎、普遍、少數、很多、許多、不少」這類詞，同一句要有數字標記（R15）。
  - 摘要、分布、延伸觀察提到的縣市，要是資料包標「可直接提」的（數量或比例前五名）；其他縣市要在同一段附上它的數字標記（R14）。
  - 縣市寫全名（新竹縣、臺南市），不寫「新竹」「台南」。
  - 由來沒寫的事不要補：不加年代、人物、族群的推論；要提就逐字引用。
  - 地名含這個字不代表意思都一樣；不同地區意思不同時分開寫，各舉代表地名。
- 原住民族的舊稱（例如「番」）只出現在「」引文或地名引號裡，說明文字用「原住民族」或由來裡的族名。
- 內容檔不寫HTML、Markdown粗體、連結或圖片。

## 7. 網頁風格

新增字不必動版面；要改版面才讀這一節。

- 母題是生字簿：大字放在田字格裡、用楷書；結構線用田字格的綠，資料點和選取用紅筆的紅。
- 顏色只用`assets/style.css`開頭的變數，不在別處寫死色碼：

| 變數 | 色碼 | 用途 |
|---|---|---|
| `--paper` | #fbfcfa | 頁面底色 |
| `--ink` | #222724 | 內文、已收錄的字 |
| `--pencil` | #69716b | 次要文字 |
| `--trace` | #a7afa9 | 還沒收錄的字（描紅） |
| `--grid` | #6f9c7d | 田字格、表格線、比例長條 |
| `--red` | #c4372c | 地圖上本頁的字、數量長條、選取狀態 |

- 字型：大字和標題用LXGW WenKai TC（楷書），內文用系統黑體。
- 單字頁的結構固定在`templates/zi.html`：田字格大字＋標題＋摘要＋四項數字→分布（地圖、說明、縣市表）→字義→代表地名→延伸觀察→相關字→資料與檢查。

- 改版面就改樣板或`style.css`，讓所有頁面一起變；不要只為某一頁加特例。
- 手機寬度375px不能出現橫向捲動；地圖上的點要能用鍵盤選取。

## 9. 修改既有內容、規則或資料

- 改內容檔：更新「更新」日期，`log.md`加`## [YYYY-MM-DD] 修改｜<字>`並寫原因；不要順手改其他字。
- 改規則（本檔）或程式：`log.md`用「規則」或「程式」，寫改了什麼；本檔和`check.py`一起改，讓每條規則都有檢查。
- 換新版原始資料：新檔放進`data/raw/`，更新`data/SOURCE.md`的日期與SHA-256，`log.md`記「資料」，重跑`build.py`，再逐字確認分布段落的說法還成立。

## 5. 候選代表地名（有官方由來的288處裡列出60處）

內容檔的代表地名照「- P編號 地名（縣市鄉鎮）」抄寫，例如「- P03049 圍仔內（嘉義縣東石鄉）」。

### 嘉義縣

- P03049｜圍仔內｜嘉義縣東石鄉圍潭村
  - 由來（田野調查）：一說： 明末清初，先祖隨鄭成功自福建泉州來台，在此定居，可能因先民來自圍仔內小部落，落地生根後，為飲水思源便因襲固里舊名，將所居住村落名『圍仔內』，居民以蔡、莊兩姓為多。／二說：居民沿朴子溪流經而居、飲水洗滌灌溉十分便利，但每年都有幾次氾濫，造成家園流離失所，居民乃合力以土堤圍高，減少水患次數，庄內乃名『圍仔內』。
- P04763｜圍仔內｜嘉義縣布袋鎮東港里
  - 由來（田野調查）：「圍仔內」因對應後東港而來，圍仔內居民邱姓先人來自廣東省潮陽縣，與北面後東港居民邱姓先人來自福建省泉州府南安縣不同，即客家人與閩南人的差異，為數較少的邱姓客家人有時受人多勢眾的後東港邱姓閩南人欺負佔便宜，故自圍籬笆或圍牆以區隔自保，但後來因人口增加，圍仔內向東擴充至縣道161之東。
- P03021｜竹圍仔｜嘉義縣大林鎮西結里
  - 由來（田野調查）：竹圍仔位於華興溪(倒孔小溪)南畔,曩昔恐洪水侵蝕村莊,故植刺竹於溪岸當護堤,又因東北角,溪勢急轉彎,溪岸農田沖積許多細沙而成著名的」大砂壩」,每到東北季風吹起,塵沙飛揚,村莊周圍植刺竹林,充為防風林,因而整個村莊環繞刺竹,因而得名。
- P02477｜竹圍仔｜嘉義縣大埔鄉茄苳村
  - 由來（田野調查）：日據時代以前，由於治安不好，土匪又多，常出沒百姓之家搶劫糧食財物。此地種植大量的刺竹，居民乃將刺竹砍下築一城門，將聚落層層圍住，以防土匪入侵。後因日人統治，治安改善，才將刺竹城門毀之，然而此地居民仍將它命為「竹圍仔」。
- P02423｜大竹圍｜嘉義縣竹崎鄉沙坑村
  - 由來（田野調查）：本地之地名由來乃是因在有清一代治安不好，常有土匪打家劫舍，為了防止土匪偷襲，故便在村落的四周種莿竹以為屏障，圍在村莊的四周，故稱『大竹圍』。
- P03572｜下竹圍｜嘉義縣民雄鄉東榮村
  - 由來（田野調查）：下竹圍為古早打貓街間隔頂竹圍（竹圍仔內）的南面聚落，因古早為防風雨與防盜作用，而於四周栽植竹林作籬笆，稱之為「下竹圍」。

- P13534｜大竹圍｜新北市三重區
  - 由來（田野調查）：大厝周圍植刺竹，由於先人遷台甚早，竹圍既高且大，故稱之為大竹圍。

### 臺南市

- P26440｜下角帶圍｜臺南市新營區角帶里
  - 由來（地名辭書）：庄名下角帶圍由來眾說紛紜（庄民多簡稱角帶圍），一說為早期角帶圍聚落因北方有一灌溉渠道，東邊有一堤防，該聚落由此大圳與堤防所包圍，部落中有李、張、邱姓三個角頭，故稱角帶圍；另一較為可信的說法是：因早期庄東、南、北遍植刺竹，彷如屏障，成角帶圍庄之勢（黃文博，1998），故名，此地位處鹽水東南隅，早年應係拱衛大奎壁庄，故亦稱下角帶圍。
- P26319｜竹圍後｜臺南市後壁區竹新里
  - 由來（地名辭書）：清中葉後至清末由於店仔口（白河）以西的平野土匪橫行，時常出沒搶奪民家財物，墾民為保護自己的生命和財產安全，在聚落的四週遍植刺竹，一則圍籬防盜，二則竹葉可當薪材，因此整個庄頭為竹林所圍，但在竹圍後方（南邊）埤池密佈，所產的魚美味可口，居民多挑到鹽水港街販賣，因此稱之為竹圍後庄。
- P27029｜角帶圍｜臺南市新營區角帶里
  - 由來（地名辭書）：因位處某地外圍，儼若其屏障拱衛之地，成角帶圍庄之勢，故名。此地位處鹽水東南隅，早年應係拱衛「大奎壁庄」（鹽水），故亦稱「下角帶圍」。
- P28370｜竹圍埔｜臺南市東山區東原里
  - 由來（地名辭書）：由前大埔沿南104線道往青山方向，當南99-1線交叉處附近。是一處地勢低平，四周空曠，於是早年居民於四周遍植刺竹作為圍籬，故名。
- P28169｜竹圍仔｜臺南市將軍區忠興里
  - 由來（地名辭書）：在「姓周仔」之北、加油站之南的「南十九線（漚汪－苓仔寮）道路」之東的小庄，昔日刺竹圍厝為籬，故稱「竹圍仔」，以黃為大姓。
- P27861｜新圍仔｜臺南市北門區鯤江里
  - 由來（地名辭書）：由南鯤鯓廟過急水溪即為新圍仔，蚵寮人和灰?港人所新墾圍建之庄，舊稱威裡，戰後設村為新圍村，大村制時併入鯤江村。
### 臺中市

- P21994｜大仔圍｜臺中市大雅區四德里
  - 由來（地名辭書）：屬於四塊厝的一部份，又稱大竹圍、保正仔，以張、廖姓為主。地名起因是本地以前有一座大伙房，四周圍還有一座大型的竹圍，住在其中的人有多位擔任保正一職，極為富有。或作長枝仔竹圍。（2008年田野調查結果）
- P22502｜下竹圍｜臺中市大里區瑞城里
  - 由來（地名辭書）：據居民口傳，早期本地有許多竹林，故名竹圍，「下」字則相對於北方的頂竹圍而言。因與塗城聚落同屬塗城大字，為有別與塗城聚落，目前亦有居民將此地稱呼為「下塗城」。
- P23085｜竹圍｜臺中市霧峰區甲寅里
  - 由來（地名辭書）：居民口傳本地為林甲寅故居所在之處，早期因聚落周圍遍植竹林，故有「竹圍」之稱。後期來此聚居者，往原竹圍聚落的北方定居，為求區隔，故有頂、下竹圍之分。
- P23573｜頂竹圍｜臺中市外埔區馬鳴里
  - 由來（地名辭書）：因居民於聚落外圍種植竹林而名，又因位於馬鳴埔聚落之東南處，為水頭一帶，因故又稱為頂竹圍。
- P22739｜後竹圍｜臺中市大甲區武曲里
  - 由來（地名辭書）：早年黃姓移民在此落居建屋，於聚落南圍栽植竹林，因聚落位於橫圳庄的南側，而名為後竹圍。
- P23296｜竹圍仔｜臺中市清水區高美里

### 高雄市

- P37284｜竹圍｜高雄市新興區漢民里
  - 由來（地名辭書）：聚落名，新興區的舊部落又稱中竹圍或頂竹圍，在今民生一路、中山一路與林森二路交接之處，原光華里與泰明里一帶。當時居民多以竹林種植於住宅四周，做為圍籬之用，有抵禦盜賊、防風的作用，既可取竹筍或採為建築之用，經繁衍後住戶漸多，乃有「竹圍」之稱，是大港埔的開基地。（四）起元大港埔（Khi-guan-t?i-kang-poo）（22°37’39.4”N,120°18’08.4”E）聚落名，指大港埔最早起源之處，即舊部落竹圍的所在地。
- P37365｜林投圍｜高雄市前金區林投里
  - 由來（地名辭書）：聚落名，大約位於前金二街南北、東到成功一路，南到大同二路一帶，西到市中一路，可能是因聚落附近有林投樹（又名莿棘），且該聚落的集居狀態或有防禦性的圍籬，故被稱為「林投圍」。林投圍聚落的四周，從日治時代（1895-1945）開始由農地改為建地，多呈棋盤式街廓，舊合院屋社被包圍在街廓內，走入巷內，才得以一見舊聚落；在街廓內的聚落則因產權分屬多人，改建困難，仍保有舊聚落樣貌。聚落外的臨路屋舍早就蓋成2樓樓房，但相對於附近街廓的4、5樓透天房舍或高樓群，林投圍的外觀顯得舊老舊。
- P37282｜下竹圍｜高雄市新興區玉衡里
  - 由來（地名辭書）：聚落名，在今中山一路、五福二路與林森一路交接之處，為本區舊部落。因居民多以竹林種植於住宅四周，做為圍籬之用，有抵禦盜賊、防風的作用。其發展晚於竹圍，且在竹圍南邊，乃有「下竹圍」之稱，大統百貨五福店、新興國民中學都在此地。
- P35251｜大竹圍｜高雄市旗山區新光里
  - 由來（地名辭書）：可能是與位在東北方的竹圍有所區分，故稱大竹圍。
- P35349｜圍內｜高雄市大樹區溪埔里
  - 由來（地名辭書）：因其居住的房舍過去以剌竹圍籬，故名。
- P35312｜竹圍仔｜高雄市旗山區南洲里
  - 由來（地名辭書）：原本聚落外面圍以竹林，故稱竹圍仔。
### 苗栗縣

- P31730｜竹圍｜苗栗縣銅鑼鄉樟樹村
  - 由來（田野調查）：舊稱竹圍子莊，昔日盛產桂竹，遠望儼似竹山一般，聚落則零星散居各處，由於當地時受土匪侵擾，地方民眾遂決議於聚落四周種植刺竹，權充圍牆，以為護衛，久之便以竹圍為名。
- P32420｜石圍牆｜苗栗縣公館鄉石墻村
  - 由來（田野調查）：約百十年前先民吳芳霖率眾來此開庄，為防番人侵犯，以石築牆，圍成一庄，故名。
- P32241｜竹圍仔｜苗栗縣通霄鎮城北里
  - 由來（田野調查）：在圓仔山腳下，因竹林圍繞著聚落，故以「竹圍」稱之
- P31996｜圍牆肚｜苗栗縣苗栗市青苗里
  - 由來（田野調查）：清末有地主湯氏曾以牆圍之，牆內之地即以此名之
- P32020｜竹圍仔｜苗栗縣竹南鎮營盤里
  - 由來（田野調查）：本處聚落之周圍，圈植有竹欉，故名。
- P32006｜下竹圍｜苗栗縣竹南鎮新南里
  - 由來（田野調查）：本區南方有一竹圍之聚落，故名。
### 雲林縣

- P34733｜林投圍｜雲林縣口湖鄉埔北村
  - 由來（地名辭書）：地名義指環植林投樹的圍籬，林投是海濱沙地上的野生植物。早期各部落間多植林投樹成列，當時稱作「林投巷」。林頭圍也稱東圍，因為東圍和中圍都是以吳姓居民為主，且相同淵源，林投圍位置在東，故稱東圍。
- P34958｜下竹圍｜雲林縣崙背鄉舊庄村
  - 由來（地名辭書）：本地居民以詹姓為主，約一百年前，原居於彰化縣竹塘鄉的竹圍地區，因遭盜匪搶劫財物，有感於當地治安不靖，乃南移至本地，並沿用原鄉地名，故本地稱為「下竹圍」。
- P34619｜頂竹圍｜雲林縣虎尾鎮頂溪里
  - 由來（地名辭書）：又稱陳竹圍，因本地居民幾乎都姓陳。開發早期時為防盜匪，種竹林將聚落圈圍起來，又位於下竹圍北邊，因而稱為頂竹圍。
- P34616｜下竹圍｜雲林縣虎尾鎮中溪里
  - 由來（地名辭書）：地名的由來是因早期治安不佳，先民乃在聚落外圍種植竹林防禦盜匪，因位在頂竹圍的南方，故稱「下竹圍」。
- P34613｜竹圍仔｜雲林縣大埤鄉北鎮村
  - 由來（地名辭書）：地名起源於古時聚落四周多竹子，故名為大竹圍，亦即被竹子包圍的聚落，現居民稱為竹圍仔
- P34369｜竹圍｜雲林縣二崙鄉楊賢村
  - 由來（地名辭書）：因先民為防禦盜匪，在聚落周圍圈種刺竹，僅留一處入口和一處出口，故稱之「竹圍」。
### 宜蘭縣

- P06089｜零工圍｜宜蘭縣冬山鄉八寶村
  - 由來（地名辭書）：零工，一說為男工，由於該地為山地住民下山的門戶，形勢險要，皆為男丁駐守，故稱之為男工圍。一說為臨時工，乃短期駐防的隘丁
- P06116｜竹圍仔底｜宜蘭縣冬山鄉武淵村
  - 由來（地名辭書）：位於富農路東側武煙圳旁的集村聚落，是練姓之同姓集村，由於聚落四周圍以竹圍，故稱之為竹圍仔底。
### 臺北市

- P25085｜頂竹圍｜臺北市松山區民有里
  - 由來（地名辭書）：意指上方的竹圍聚落。今民福與民有兩里，昔有兩處聚落分布，聚落皆有竹子包圍，位於北方民福里境內的聚落，地處較下游地勢稍低處，故稱下竹圍，位於南方民有里境內的聚落則被稱作頂竹圍。
### 新竹市

- P15642｜頂竹圍｜新竹市東區頂竹里
  - 由來（地名辭書）：十年(1894)住有「戶二十二，丁口一百一十七人」。（陳朝龍，1962：74）據聞，清代末期枕碩山腳的聚落，其房屋周圍均種有竹圍；自竹塹出土城小南門（耀文門，址在南壇（大眾廟）北側）到枕碩山途中，頂竹圍是第一個碰到的有竹圍的聚落，故名頭竹圍；後來，因頭竹圍座落的地點，地勢較高，故逐漸演化成頂竹圍。日治中期以後，頂竹圍指涉的地域，已擴及東南街兩側。

  - 由來（田野調查）：竹子茂盛，方圓數十公尺圍繞。

  - 由來（田野調查）：早年戴家在此落腳，聚落四周圍種刺竹，故名。
### 南投縣

- P00353｜竹圍仔｜南投縣竹山鎮竹圍里
  - 由來（地名辭書）：竹圍仔有二義，其一為聚落名；其地名由來有二說，一說為明朝永曆年間，林圯率部入墾此地驅逐布農族後，繼有福建省漳州府平和、南靖縣人林新彩及張廖二姓漢民陸續進入本地拓墾，為抵禦原住民族攻擊，而於聚落周圍環植莿竹林，故名。另一說本地為「前山第一城」舊址，因築城時先環植莿竹三重以鞏固垣基，而得名。城址所在亦漸轉變為居民耕作之田園，其確實之位置已不可考。此外，因其位居平坦台地上方，附近山峰層巒疊翠，林木生茂，且早晚為雲霧嬝繞，故又有「雲林坪」之稱。其二指日治時期的大字名，範圍包含今下坪、雲林、竹圍、??四里全部，及中正里中西部。
### 屏東縣

- P07257｜新圍(老古新庄)｜屏東縣鹽埔鄉新圍村
  - 由來（地名辭書）：根據當時容易氾濫的自然環境，再加上此地在明治三十四年（1901）左右有鹽埔新庄、明治三十七年（1904）有新為庄仔之稱，以及片段的口傳歷史綜合推論，位於現在糖廠所屬西海豐農場（昔日稱舊溪路）之處，即是番仔寮（今長治鄉繁華等四村）的舊址，當時堤防尚未興建，雨季來臨，隘寮溪水患淹沒聚落，導致部分居民遷居到此，因為當時北方已有鹽埔庄，於是將此地命名為鹽埔新庄。而又因本聚落是新近產生的村莊，所以稱為新為庄仔，之後再簡稱為新圍。

### 嘉義市

- P01081｜新竹圍仔｜嘉義市西區重興里

### 基隆市

- P05877｜竹圍內｜基隆市仁愛區書院里
