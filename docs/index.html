臺灣地名用字地圖

內政部記錄了33,923處聚落的地名，其中21,096處附有官方說明的由來。這個網站一個字做一頁：畫出地名含這個字的聚落在哪裡，再引用官方由來說明這個字在地名裡的意思。目前收錄1個字。

  • 窩窩：三面環山的凹地441處

每張小地圖的紅點是地名含這個字的聚落。點進一個字，可以看各縣市的數量、比例和代表地名。
